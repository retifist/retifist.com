# Sheet Delamination and Seam Failure

Human page: https://retifist.com/literature-reviews/sheet-delamination-seam-failure

## Executive summary

Read the broken cement line before adding glue. Adhesive failure leaves cement on one adherend; cohesive failure splits the cement; fiber-pull vs rubber-tear sorts textile vs sheet.[^1][^2] Edge lift tracks lap geometry and stretch. ASTM D903 and D1876 are peel method classes, not a garment photo atlas.

Pair with [Sheet adhesives](/literature-reviews/sheet-adhesives-and-seam-integrity) and [Sheet latex–textile bonding](/literature-reviews/sheet-latex-textile-bonding).

## Peel modes

| Mode | Cue | Class |
| --- | --- | --- |
| Adhesive | Cement one side only | Interfacial prep / contamination / polarity |
| Cohesive | Cement split | Weak or aged cement layer |
| Fiber-pull | Textile in the cement | Textile side lost |
| Rubber-tear | Sheet fails away from the interface | Sheet weaker than the bond; notch / design |

Peel rate can flip cohesive ↔ adhesive in a cited PSA system.[^3]

## Morphology

| What you see | Likely class |
| --- | --- |
| Clean rubber, cement on tape / lining | Adhesive — slick nylon / no prep |
| Orange-peel texture in cement | Contamination / incomplete dry |
| Edge lift only | Stretch / peel leverage at the lap |
| Rubber torn at a sharp inner corner | Notch / design |

## Decision flow

```text
1. Inspect both faces
2. Classify mode
3. Edge vs mid-panel
4. Fresh vs months (oxidation / heat)
5. Re-prep vs redesign lap vs retire
```

## Aged cement

Heat/oxidation can soften or embrittle films and adhesive layers.[^4]

Copper or oily plastic: [Sheet aging](/literature-reviews/sheet-aging-storage-and-care).
