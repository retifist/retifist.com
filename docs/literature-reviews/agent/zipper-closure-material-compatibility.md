# Zipper Closure Material Compatibility

Human page: https://retifist.com/literature-reviews/zipper-closure-material-compatibility

## Executive summary

Compatibility only — not install. Nylon coil needs prep bridge; smooth filament poor mechanical bond.[^1] Rubberise = industrial strategy. Shrink on aqueous tape.[^2][^3] ASTM D2054 = zipper tape textile only.[^4]

## Components

| Part | Question |
| --- | --- |
| Woven tape | Fiber, shrink, rubberise prep |
| Coil / teeth | Nylon vs metal → article 21 |
| Stops / pull | Material + cleaner exposure |

## Decision cues

```text
cotton → mechanical key; shrink if aqueous
nylon/PET → prep bridge required
sheet-based solvent → article 01
aqueous on tape → shrink check
metal coil → matrix 20 + hardware 21
```
