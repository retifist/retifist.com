# Liquid Latex Painting vs Compounding Pigment

Human page: https://retifist.com/literature-reviews/liquid-latex-painting-vs-compounding-pigment

> **Safety.** Read TDS/SDS. Food-contact colorants ≠ wear clearance.

## Executive summary

**Compounding pigment** tints NR before film formation. **Surface paint** is a separate layer — often a **different polymer**. Consumer “latex paint” bottles need TDS polymer ID. Use this when decoding product names.

---

## Three classes

| Class | Path |
| --- | --- |
| Compound pigment (dispersed in latex) | Liquid latex work[^1][^2][^3] |
| NR surface coat / prevulc deposit | Decoration branch[^4] |
| Acrylic/wrong polymer | Rejected for NR compound |

---

## Compound prep

Dispersion **<5 µm**; emulsify oils first.[^2][^3]
