# Edge Finishing Materials: Tubes, Tape, and Binding Choices

Human page: https://retifist.com/literature-reviews/edge-finishing-materials

## Executive summary

Edge finishing is a material choice: NR tube/strip, rubberised tape, or spread-coat analog. Wrong family → edge lift, shrink ripple, stiff rim. **Sheet-based:** strip/tube + solvent-cement culture. **Liquid-latex:** aqueous spread on textile — shrink/migration risks. Names families; not a fold tutorial.

Aqueous latex adhesives shrink fabrics.[^1][^2] Porous tape → mechanical key; slick faces → polarity match.[^3][^4]

## Material families

| Family | Risk cue |
| --- | --- |
| NR tube/strip | Gauge match |
| Rubberised tape | Prep (see article 05) |
| Cotton binding | Aqueous shrink[^1] |
| Smooth filament | Polarity bridge |

## Decision cues

```text
straight high-stress → strip/tube
sheet-based → solvent family (01)
liquid-latex → shrink check on textile
porous → mechanical key; slick → polarity match
```
