# Compatibility Matrix: Metals, Oils, Plastics, and Skin Products

Human page: https://retifist.com/literature-reviews/compatibility-matrix-metals-oils-plastics

## Executive summary

v1 never/avoid/conditional/OK grid for NR liquid and sheet. **Liquid-latex:** no brass/copper/galvanized wet contact.[^1][^2] **Sheet-based:** Cu/Mn aging and oil swell still apply.[^3][^4] Petroleum skin products attack latex barriers.[^5][^6]

## Matrix — metals

| Contact | Liquid | Sheet |
| --- | --- | --- |
| Brass/copper | Never | Avoid |
| Galvanized wet | Never | Avoid wet |
| Stainless clean | Conditional | Conditional |

## Matrix — oils

Petroleum/mineral skin products: **Avoid**.[^5][^6] NR < CR oil resistance.[^7]
