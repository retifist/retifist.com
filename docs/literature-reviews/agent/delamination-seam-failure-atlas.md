# Delamination & Seam Failure Atlas

Human page: https://retifist.com/literature-reviews/delamination-seam-failure-atlas

## Executive summary

Read the broken bond first. Adhesive vs cohesive vs fiber-pull vs rubber-tear. Edge-lift often stretch/stress. ASTM peel methods are lab classes, not garment atlases.[^1][^2]

## Peel modes

| Mode | Cue |
| --- | --- |
| Adhesive | Cement one side only |
| Cohesive | Cement split |
| Fiber-pull | Textile in cement |
| Rubber-tear | Rubber fails bulk |

Peel rate can flip mode.[^3]

## Morphology → cause

| Morphology | Cause | Workflow |
| --- | --- | --- |
| Clean rubber, cement on tape | Adhesive — nylon/no prep | Sheet textile |
| Cement dust both sides | Starvation / open time | Sheet |
| Ply split cast hood | Multi-dip timing | Liquid-latex |
| Edge lift only | Stretch mismatch | Sheet textile |

## Decision flow

```text
1. Split bond — inspect both faces
2. Classify mode
3. Edge vs mid-panel
4. Fresh vs aged
5. Sheet vs liquid-latex vs multi-dip
6. Re-prep vs redesign vs retire
```

Cross-links: `01` glue, `05` textile, `19` edge, `20` oil/contamination.
