# Reduction and pressure sensitivity

Human page: https://retifist.com/literature-reviews/reduction-and-pressure-sensitivity

> **Experimental verification in progress.** These planning numbers have not been bench-checked against worn sheet yet. Treat them as working marks, not shop-verified claims.

## Executive summary

*P*_feels = *P*_target / *m*_C with Scale **C** only (arm/forearm *m*_C=1). A = noticeability; B = pain ceiling.[^1][^2]

Draft *m*_C bands — not latex-wear validated.[^3]

## Reference cell

Skintight fashion band: *t*₀=0.39 mm, *r*=12%, soft *G* → *T*≈81 N/m; mid-limb *R*=10 cm → *P*≈0.81 kPa.[^4]

| Site | *P* | *m*_C mid | *P*_feels |
| --- | --- | --- | --- |
| Mid-limb | 0.81 | 1.00 | 0.81 |
| Arm | 1.62 | 1.00 | 1.62 |
| Wrist | 2.70 | 1.35 | 2.00 |
| Waist ventral | 0.68 | 0.50 | 1.36 |

---

## Equal-% partial cancelation

Same *r* → shared *T*; *P*=*T*/*R*. Distal high *m*_C softens feel vs raw *P*; ventral low *m*_C raises feel vs soft raw *P*. Wrist/waist: physical **~4×** (2.70/0.68) vs feels **~1.5×** (2.00/1.36) — partial, not full equalization.[^4][^5]

Body-wide (excl. neck/face): *P* span ~4×; *P*_feels ~2.6× — tighter, mixed. Outliers: neck proxy, underbust + Scale B, face (no hoop *P*).[^5]

---

## Proxies / rules

Extended regions reuse Clo3D waist/arm/mid-limb *P* as budgeting stand-ins only.[^5] Use C for formula; low-end *m*_C + Scale B on neck/face/underbust/ventral waist; never Scale A in formula.[^1][^2]

Examples: hug waist 0.49/0.50≈0.98; skintight wrist ~2.0 after distal soften; tailored waist 0.29/0.50≈0.58.[^4][^5]

Physiology ≠ VAS comfort (airway/respiration).[^2][^6]
