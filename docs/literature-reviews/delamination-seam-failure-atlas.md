# Delamination & Seam Failure Atlas

## Executive summary

Read the broken bond before adding glue. **Adhesive failure** leaves cement on one side only. **Cohesive failure** splits the cement layer. **Fiber-pull** vs **rubber-tear** tells textile vs rubber weak link. Edge-lift often tracks stretch mismatch and stress concentrators.

ASTM defines peel **method classes**, not garment photo atlases. Use with [Adhesives and Seam Integrity](/literature-reviews/adhesives-and-seam-integrity), [Latex Textile Bonding](/literature-reviews/latex-textile-bonding), [Edge Finishing Materials](/literature-reviews/edge-finishing-materials), and [Compatibility Matrix](/literature-reviews/compatibility-matrix-metals-oils-plastics).

## Peel mode definitions {#peel-modes}

| Mode | What you see | Likely cause |
| --- | --- | --- |
| Adhesive | Cement on one adherend only | Interfacial prep/contamination |
| Cohesive | Cement split thickness-wise | Wrong strength or aged rubber phase |
| Fiber-pull | Textile fibers in cement | Textile side weak |
| Rubber-tear | Rubber fails away from interface | Rubber weaker than bond |

Peel **rate** can flip cohesive ↔ adhesive in PSA studies — slow edge-lift ≠ fast lab peel.

<details>
<summary>What is adhesive vs cohesive failure?</summary>

**Adhesive failure** means the glue let go from one surface — the rubber or textile face is clean. **Cohesive failure** means the glue itself tore apart — both sides show cement. Which mode you see tells you whether to fix prep, glue choice, or the rubber compound — not just "add more cement."

</details>

## Morphology → likely cause {#morphology}

| Morphology | Likely cause class | Workflow |
| --- | --- | --- |
| Clean rubber face, cement on tape | Adhesive — slick nylon / no prep | Sheet textile |
| Cement dust both sides, thin ghost | Starvation / open time | Sheet |
| Orange peel texture in cement | Contamination / incomplete dry | Sheet |
| Mid-panel bubble peel | Migration/plasticizer | Both |
| Ply split cast hood | Multi-dip timing | Liquid-latex |
| Edge lift only | Stretch mismatch | Sheet textile |

## Decision flow {#decision-flow}

```text
1. Split the bond — inspect both faces
2. Classify mode (adhesive / cohesive / fiber / rubber)
3. Location? edge vs mid-panel
4. Age? fresh vs months — oxidation/migration branch
5. Workflow? sheet cement vs liquid-latex aqueous vs multi-dip
6. Fix class: re-prep vs redesign vs retire — not a construction repeat
```

---

## Aged failure {#aged-failure}

Sulfur-donor cure PSAs age better than free-sulfur systems. Heat and oxidation soften or embrittle films and adhesive layers. NR latex adhesive retains high-MW rubber vs solvent — different shear/peel expectations.
